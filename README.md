# FC Barcelona — Més que un club

라리가 1993/94~2026/27(진행 중 시즌 포함)을 중심으로 바르셀로나를 정리한 Streamlit 대시보드.
공개 데이터 다섯 곳을 직접 수집해 모든 수치를 원본에서 계산한다.

**배포** — https://fc-barcelona-dashboard-vepaejsjfiwxmqjzmjgven.streamlit.app

**이어서 작업한다면 [HANDOFF.md](HANDOFF.md)를 먼저 읽을 것.** 함정과 남은 작업이
정리돼 있다.

역대 레전드와 감독은 모바일에서도 빠르게 접근하도록 이름·활동 기간 선택기로
탐색한다. 연계 네트워크는 최신 시즌을 기본으로 보여 첫 화면의 과도한 길이와 복잡도를
줄였다. `전체`를 고르면 기존 전 시즌 분석도 그대로 이용할 수 있다.

전체 범위 필터는 관련 요약·차트·표에 적용한다. 슛의 `슈팅 맵에서 골만 보기`와
연계 지도의 `최소 연결 횟수`처럼 특정 차트에만 적용하는 제어는 별도로 표시한다. 점유율·이벤트·FBref
기록이 부분 표본이면 해당 표본 수와 한계를 화면에 함께 표시한다.

## 데이터 소스

| 소스 | 담당 | 범위 |
|------|------|------|
| football-data.co.uk | 라리가 경기 결과 | 1993/94~2026/27 · 1,265경기 |
| FBref | 선수 스탯, 전 대회 경기 | 33시즌 · 대회별 3,443행 |
| StatsBomb Open Data | 이벤트(슛·패스 좌표) | 531경기 · 패스 367,738 |
| Understat | 슛 좌표·xG | 2014/15~2025/26 · 11,508건 |
| Transfermarkt | 선수·감독 사진, 감독 이력 | 사진 341장 |

StatsBomb의 법적 이름은 FBref·Understat의 통용 선수명으로 맞춘다. 호나우지뉴와
호나우두처럼 이름이 충돌하는 경우는 명시적 별칭과 회귀 검사로 구분한다.

## 실행

```bash
pip install -r requirements.txt      # 대시보드 실행용
python build_data.py                 # 원본 CSV → 집계
streamlit run app.py
```

수집 스크립트까지 돌리려면 `requirements-dev.txt`를 쓴다(크롬 자동화·sklearn 포함).
Cloud에서는 수집이 돌지 않으므로 배포에는 `requirements.txt`만 필요하다.

수집부터 다시 하려면 HANDOFF.md의 실행 순서를 따를 것.

| 항목 | 값 |

| 리그 경기 | 1,265 |
| 리그 우승 | 16회 |
| 총 득점 | 2,889 (경기당 2.28) |
| 통산 전적 | 823승 240무 202패 (승률 65.1%) |
| 최고 승점률 | 2.63 (2012/13, 승점 100) |

위 누적 기록은 진행 중 시즌의 수집된 3경기를 포함한다. 완료 33시즌만 보면
1,262경기, 820승 240무 202패, 2,877득점이다. 우승은 완료 시즌만 집계한다.
수치는 저장된 데이터 기준이며 실시간 기록이 아니다.

순위는 라리가 규정대로 **승점 → 동률 팀 간 상대전적 → 골득실** 순으로 산출한다.
골득실을 먼저 적용하면 2006/07이 실제와 뒤집힌다.

## 알려진 한계

페이지 안에도 명시돼 있다. 자세한 내용은 **데이터 제공 범위** 페이지 참고.

- 홈·시대분석·엘클라시코·감독 성적은 라리가만 집계한다 (전 대회 데이터는 별도)
- 패스 맵은 2020/21까지 — 패스 좌표를 주는 무료 소스가 StatsBomb뿐이다
- FBref가 라리가 세부 패스·수비 지표를 빈 값으로 내려준다 (StatsBomb으로 대체)
- AI 모델은 정확도로 기준선을 넘지 못한다. AUC 0.629는 한 번의 시간순 평가 구간 결과이며 일반화 성능을 보장하지 않는다
- 고급 기록은 실제 출전시간이 아닌 이벤트 기록 경기 수로 나눈 경기당 지표다. 교체 출전과 풀타임을 보정하지 않는다
- 티키타카 지수는 공식 지표가 아니라 이 대시보드가 정의한 합성값이다
- 연계 네트워크는 StatsBomb·Understat의 도움 있는 라리가 골을 합치며 컵대회 조합은 빠진다

## 일일 개발 운영

이번 주 출시 마감 기준과 미완료 검증은 [출시 체크리스트](docs/RELEASE_CHECKLIST.md)에 기록한다.
자동 검사 통과는 데이터의 모든 의미·이미지 사용 권리·브라우저 동작까지 보증하지 않는다.

매일 KST 09:15에 Codex의 기존 채팅방 예약 작업으로 작은 개선과 검수를 수행한다.
에이전트 역할과 운영 기준은 `AGENTS.md`, 실행별 기록과 재개 지점은 `HANDOFF.md`를 따른다.
재사용할 에이전트 지시문은 `docs/AGENT_PROMPTS.md`에 기록한다.
짧은 재개 요약은 `docs/CURRENT.md`를 사용하며 전체 대화 복제와 반복 로그 출력을 줄인다.
토큰 절약 도구의 설치·측정 결과와 한계는 `docs/TOKEN_BENCHMARK.md`에 기록한다.
검증한 변경은 GitHub에 반영하고 Streamlit Cloud 배포 확인 결과를 같은 채팅방에 보고한다.

데이터 제공 범위 페이지에는 소스별 실제 시즌 범위, 최신 관측값과 로컬 파일
갱신 시각(KST)을 표시한다. Parquet·JSON·사진 및 묶음 데이터 캐시는 파일 목록과
수정 정보를 키에 포함해 수집 산출물이 바뀌면 다시 읽는다.

## 이미지 안내

클럽 엠블럼은 FC Barcelona 소유. 커먼즈 사진은 저작자·라이선스를 각 페이지
하단에 표기한다. 일부 선수·감독 사진은 개인 포트폴리오 용도로 직접 넣은 것이다.

라 마시아 페이지에는 공식 구단 자료 기반 역사 연표, 대표 선수 5명과 세대 계승을
표현한 AI 일러스트가 있다. 실제 선수 얼굴과 설명은 별도의 대표 선수 카드로 표시한다.
