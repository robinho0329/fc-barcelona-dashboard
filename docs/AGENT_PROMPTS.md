# 정합성 검수 팀 프롬프트

## 공통 지시

AGENTS.md, README.md, HANDOFF.md와 Git 상태를 먼저 읽는다. 문서의 숫자를
정답으로 가정하지 않고 실제 산출물과 집계 코드를 대조한다. 전체 시즌/완료 시즌,
라리가/전 대회, 팀 전체/선수 표본을 구분한다. 사실과 추정을 분리하고 문제마다
파일 위치, 재현 방법, 기대값과 실제값을 보고한다. 독립 작업만 병렬 수행하며
담당 외 파일은 수정하지 않는다. 변경은 apply_patch를 사용한다. 커밋과 push는
메인만 수행한다. 동료의 변경을 되돌리지 않는다.

## 데이터 검증 담당

읽기 전용으로 processed 데이터에서 시즌 수, 경기 수, 승무패, 득실점, 승률,
우승과 엘클라시코 기록을 직접 산출하라. 2004/05 복구와 감독·시대 집계의
일치도 확인하라. 계산 근거와 결과를 메인에 전달하라. 데이터 재생성은 금지한다.

## 화면 정합성 담당

views/*.py만 담당한다. 화면 설명과 계산 조건을 실제 데이터와 비교하고,
복구 전 누락 설명 및 근거가 확인된 모순을 수정하라. 서로 다른 분석 범위는
억지로 같은 숫자로 맞추지 말고 범위를 명확히 밝혀라. 캐시 구조 개편과 새 기능은
후속 단계로 분리한다. 수정 파일, 변경 이유, 실행 검증 결과를 보고하라.

## 독립 QA 담당

tools/만 담당한다. 기존 audit 검사를 읽고 경기 합계·시즌·우승·엘클라시코의
누락된 정합성 검사를 보강하라. 기존 검사를 중복하거나 구현을 그대로 복제하지
말고 원본과 산출물의 관계를 확인하라. 검사를 실행하고 남은 실패를 보고하라.

## 메인 통합 담당

독립 계산 결과로 README와 HANDOFF를 갱신하고 에이전트 diff를 검토한다.
전체 검사와 페이지 실행을 확인한 뒤 이번 변경만 커밋·push한다. 실제 배포 화면
확인 여부를 구분해 보고하고, 미완료 항목 및 다음 시작점을 HANDOFF에 기록한다.
